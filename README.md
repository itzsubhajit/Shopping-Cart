# Shopping Cart System

## Project Overview

The Shopping Cart System is a Python-based command-line application that allows users to manage products in a shopping cart. The project demonstrates CRUD operations using a simple CMD-based dashboard and Python's match-case statement.

## Features

- Add products to the shopping cart
- View all products in the cart
- Update an existing product
- Delete a product
- Exit the application
- Menu-driven CMD interface
- CRUD operations using Python
- Match-case used for menu selection

## CRUD Operations

| Operation | Function |
|---|---|
| CREATE | Add Product |
| READ | View Products |
| UPDATE | Update Product |
| DELETE | Delete Product |

## Problem Statement

Managing products in a shopping cart manually can be inconvenient and inefficient. This project provides a simple command-line shopping cart system where users can add, view, update, and delete products easily through a menu-driven interface.

## Business Perspective

A shopping cart system is an important component of an e-commerce platform. This project demonstrates the basic functionality required to manage products in a customer's cart. It can serve as a foundation for developing a larger online shopping system with product databases, customer accounts, payments, order management, and inventory tracking.
